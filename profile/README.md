# Welcome to the Immersive Data Center Management (IDCM) project

The project is part of [ApeiroRA](https://apeirora.eu/), an Important Project of Common European Interest – Next Generation Cloud Infrastructures and Services ([IPCEI-CIS](https://www.8ra.com/ipcei-cis/)).

Immersive Data Center Management reimagines how data centers are operated and experienced.

By combining digital twins, immersive extended reality (XR), and an open interoperable
architecture, IDCM transforms complex infrastructure into a spatial, immersive environment.

## Features

- **Digital Twins**: A semantic, vendor-neutral representation of
  all data center assets - from facility and hardware to the virtualization layer. Built on the Asset Administration Shell (AAS) standard, it provides a consistent, machine-interpretable data foundation that connects authoritative sources and enables holistic monitoring across infrastructure layers.

- **Immersive Visualization:** Let operators explore the data center spatially, inspect live states identify issues visually, and collaborate remotely.

- **Open, Modular Architecture:** Built on open-source, standards-based components designed to integrate across heterogeneous infrastructure environments.
